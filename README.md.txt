# Supermarket Sales Analysis

## Project Overview
This project analyses 1,000 supermarket transactions recorded between January and March 2019. The aim is to identify revenue patterns, product-line performance, branch performance, customer payment preferences, and monthly sales trends.

## Tools Used
- Microsoft Excel 2024
- PivotTables and PivotCharts
- Data cleaning and quality checks
- KPI dashboard and business insights

## Key Findings
- **Total revenue:** 322,966.70
- **Transactions analysed:** 1,000
- **Units sold:** 5,510
- **Highest-revenue branch:** Branch C
- **Most-used payment method:** Ewallet
- **Highest-revenue month:** January
- **Highest-revenue product line:** Food and Beverages

## Business Recommendations
- Investigate practices contributing to Branch C's revenue performance.
- Maintain reliable Ewallet payment facilities while supporting other payment methods.
- Investigate the differences in revenue between January, February, and March.
- Monitor Food and Beverages performance and assess opportunities to sustain sales.

## Data Quality
The dataset contains 1,000 transaction records. Checks found no duplicate invoice IDs or missing values in the key fields examined. Invalid quantities were not fully verified.

## Limitations
The data covers January–March 2019 and should not be treated as a representation of current sales. The dataset contains transaction records, not inventory-level data, so stock availability and stockout rates cannot be established.
